#### 1.3.2 run() 方法 - 核心执行逻辑

```java
@Override
public ToolExecuteResult run(BashInput input) {
    String command = input.getCommand();
    log.info("Bash command: {}", command);
    log.info("Current operating system: {}", osName);
    this.lastCommand = command;  // 记录最后一次命令

    List<String> commandList = new ArrayList<>();
    commandList.add(command);

    try {
        // 使用工厂模式创建对应操作系统的执行器
        ShellCommandExecutor executor = ShellExecutorFactory.createExecutor();
        log.info("Using shell executor for OS: {}", osName);

        // 执行命令并获取结果
        List<String> result = executor.execute(
            commandList,
            unifiedDirectoryManager.getWorkingDirectoryPath()
        );

        // 记录结果（用于状态字符串）
        this.lastResult = String.join("\n", result);

        // 返回 JSON 格式的结果
        return new ToolExecuteResult(objectMapper.writeValueAsString(result));
    }
    catch (Exception e) {
        log.error("Error executing bash command", e);
        return new ToolExecuteResult("Error executing command: " + e.getMessage());
    }
}
```

**执行流程**：
```
1. 获取命令
   ↓
2. 记录到 lastCommand（用于状态）
   ↓
3. 创建 Shell 执行器（工厂模式）
   ↓
4. 执行命令（传入工作目录）
   ↓
5. 记录结果到 lastResult（用于状态）
   ↓
6. 序列化为 JSON 并返回
```

**关键设计**：
- **状态记录**：`lastCommand` 和 `lastResult` 用于 `getCurrentToolStateString()`
- **工厂模式**：`ShellExecutorFactory.createExecutor()` 根据 OS 创建执行器
- **统一工作目录**：通过 `UnifiedDirectoryManager` 管理工作目录

#### 2.3.4 重试机制实现

```java
private ToolExecuteResult executeActionWithRetry(ActionExecutor executor, String actionName) {
    int maxRetries = 2;
    int retryDelay = 1000; // 1 秒

    for (int attempt = 1; attempt <= maxRetries; attempt++) {
        try {
            return executor.execute();
        }
        catch (TimeoutError e) {
            if (attempt == maxRetries) {
                log.error("Action '{}' timed out after {} attempts: {}", actionName, maxRetries, e.getMessage());
                throw e;
            }
            log.warn("Action '{}' timed out on attempt {}, retrying: {}", actionName, attempt, e.getMessage());
        }
        catch (PlaywrightException e) {
            // 某些 Playwright 异常不值得重试
            if (e.getMessage().contains("Target page, context or browser has been closed") ||
                e.getMessage().contains("Browser has been closed") ||
                e.getMessage().contains("Context has been closed")) {
                log.error("Action '{}' failed due to closed browser/context: {}", actionName, e.getMessage());
                throw e;
            }

            if (attempt == maxRetries) {
                log.error("Action '{}' failed after {} attempts: {}", actionName, maxRetries, e.getMessage());
                throw e;
            }
            log.warn("Action '{}' failed on attempt {}, retrying: {}", actionName, attempt, e.getMessage());
        }
        catch (RuntimeException e) {
            // 对于运行时异常，不重试
            log.error("Action '{}' failed with non-retryable error: {}", actionName, e.getMessage());
            throw e;
        }

        // 等待后重试
        try {
            Thread.sleep(retryDelay);
        }
        catch (InterruptedException ie) {
            Thread.currentThread().interrupt();
            throw new RuntimeException("Interrupted during retry delay for action: " + actionName, ie);
        }
    }

    throw new RuntimeException("Unexpected end of retry loop for action: " + actionName);
}
```

**重试策略**：
1. **最大重试次数**：2 次
2. **重试延迟**：1 秒
3. **可重试异常**：`TimeoutError`、某些 `PlaywrightException`
4. **不可重试异常**：
   - 浏览器/上下文已关闭
   - `RuntimeException`

**设计优势**：
- 提高操作成功率
- 避免无效重试（浏览器关闭等）
- 清晰的日志记录

### 2.4 getCurrentToolStateString() 实现

```java
@Override
public String getCurrentToolStateString() {
    // 只有在 run 方法至少执行过一次才初始化浏览器
    if (!hasRunAtLeastOnce) {
        return """
            Browser tool context is empty
            """;
    }

    DriverWrapper driver = getDriver();
    Map<String, Object> state = getCurrentState(driver.getCurrentPage());

    // 构建 URL 和标题信息
    String urlInfo = String.format("\n   URL: %s\n   Title: %s", state.get("url"), state.get("title"));

    // 构建标签页信息
    List<Map<String, Object>> tabs = (List<Map<String, Object>>) state.get("tabs");
    String tabsInfo = (tabs != null) ? String.format("\n   %d tab(s) available", tabs.size()) : "";
    if (tabs != null) {
        for (int i = 0; i < tabs.size(); i++) {
            Map<String, Object> tab = tabs.get(i);
            String tabUrl = (String) tab.get("url");
            String tabTitle = (String) tab.get("title");
            tabsInfo += String.format("\n   [%d] %s: %s", i, tabTitle, tabUrl);
        }
    }

    // 获取交互元素信息
    String elementsInfo = (String) state.get("interactive_elements");

    // 构建最终状态字符串
    String retString = String.format("""

        - Current URL and page title:
        %s

        - Available tabs:
        %s

        - Interactive elements and their indices:
        %s

        - Content above%s or below%s the viewport (if indicated)

        - Any action results or errors:
        %s
        """,
        urlInfo,
        tabsInfo,
        elementsInfo != null ? elementsInfo : "",
        contentAbove,
        contentBelow,
        state.containsKey("error") ? state.get("error") : ""
    );

    return retString;
}
```

### 2.5 getCurrentState() 获取页面状态

```java
public Map<String, Object> getCurrentState(Page page) {
    Map<String, Object> state = new HashMap<>();

    try {
        // 验证页面
        if (page == null || page.isClosed()) {
            state.put("error", page == null ? "Page is null" : "Page is closed");
            return state;
        }

        // 等待页面加载完成
        try {
            Integer timeout = getBrowserTimeout();
            // 先等待 DOM 内容加载完成
            page.waitForLoadState(
                com.microsoft.playwright.options.LoadState.DOMCONTENTLOADED,
                new Page.WaitForLoadStateOptions().setTimeout(timeout * 1000)
            );
            // 再等待网络空闲
            try {
                page.waitForLoadState(
                    com.microsoft.playwright.options.LoadState.NETWORKIDLE,
                    new Page.WaitForLoadStateOptions().setTimeout(3000)
                );
            }
            catch (TimeoutError e) {
                log.debug("Network idle timeout, waiting for content updates: {}", e.getMessage());
                Thread.sleep(1000); // 再等待 1 秒让内容更新
            }
        }
        catch (Exception e) {
            log.warn("Error waiting for load state, continuing anyway: {}", e.getMessage());
        }

        // 获取基本信息
        String currentUrl = page.url();
        String title = page.title();
        state.put("url", currentUrl != null ? currentUrl : "unknown");
        state.put("title", title != null ? title : "unknown");

        // 获取标签页信息
        List<Map<String, Object>> tabs = getTabsInfo(page);
        state.put("tabs", tabs);

        // 等待动态内容渲染
        Thread.sleep(500);

        // 生成 ARIA 快照
        try {
            AriaSnapshotOptions snapshotOptions = new AriaSnapshotOptions()
                .setSelector("body")
                .setTimeout(getBrowserTimeout() * 1000);

            Boolean enableShortUrl = getLynxeProperties().getEnableShortUrl();
            boolean compressUrl = enableShortUrl != null ? enableShortUrl : true;

            String snapshot = AriaElementHelper.parsePageAndAssignRefs(
                page,
                snapshotOptions,
                compressUrl,
                shortUrlService,
                rootPlanId
            );
            if (snapshot != null && !snapshot.trim().isEmpty()) {
                state.put("interactive_elements", snapshot);
            }
            else {
                state.put("interactive_elements", "No interactive elements found or snapshot is empty");
            }
        }
        catch (Exception e) {
            log.warn("Error getting ARIA snapshot: {}", e.getMessage());
            state.put("interactive_elements", "Error getting interactive elements: " + e.getMessage());
        }

        return state;
    }
    catch (Exception e) {
        log.error("Failed to get browser state: {}", e.getMessage(), e);
        state.put("error", "Failed to get browser state: " + e.getMessage());
        return state;
    }
}
```

**关键步骤**：
1. **页面验证**：检查是否为空或已关闭
2. **等待加载**：
   - DOMContentLoaded
   - Network Idle（最多等待 3 秒）
   - 额外等待 500ms 让动态内容渲染
3. **获取基本信息**：URL、标题
4. **获取标签页信息**：所有打开的页面
5. **生成 ARIA 快照**：
   - 使用 `AriaElementHelper.parsePageAndAssignRefs()`
   - 压缩 URL（如果启用）
   - 分配引用编号（[0]、[1]、[2]...）

```java
@Override
public String getCurrentToolStateString() {
    return String.format("""
        Current File Operation State:
        - Working Directory: %s
        - Last File Operation: %s
        - Last Operation Result: %s
        """,
        unifiedDirectoryManager.getWorkingDirectoryPath(),
        lastCommand.isEmpty() ? "No command executed yet" : lastCommand,
        lastResult.isEmpty() ? "No result yet" : lastResult
    );
}
```

**Browser 的复杂状态**：
```java
private volatile boolean hasRunAtLeastOnce = false;

@Override
public String getCurrentToolStateString() {
    if (!hasRunAtLeastOnce) {
        return "Browser tool context is empty";
    }

    Map<String, Object> state = getCurrentState(driver.getCurrentPage());

    // 返回 URL、标题、标签页、交互元素等
    return String.format("""
        - Current URL and page title: %s
        - Available tabs: %s
        - Interactive elements: %s
        """, urlInfo, tabsInfo, elementsInfo);
}
```

**关键区别**：
- Bash 状态：静态字段（lastCommand、lastResult）
- Browser 状态：动态获取（getCurrentState() 查询浏览器）

### 2. 错误处理模式

**Bash 的简单错误处理**：
```java
try {
    List<String> result = executor.execute(commandList, workingDir);
    return new ToolExecuteResult(objectMapper.writeValueAsString(result));
}
catch (Exception e) {
    log.error("Error executing bash command", e);
    return new ToolExecuteResult("Error executing command: " + e.getMessage());
}
```

**Browser 的多层错误处理**：
```java
// 第 1 层：参数验证
if (action == null || action.trim().isEmpty()) {
    return new ToolExecuteResult("Action parameter is required");
}

// 第 2 层：浏览器状态检查
if (driver == null || !driver.getBrowser().isConnected()) {
    return new ToolExecuteResult("Browser is not available");
}

// 第 3 层：操作执行（带重试）
try {
    result = executeActionWithRetry(() -> action.execute(), action);
}
catch (TimeoutError e) {
    return new ToolExecuteResult("Browser action timed out: " + e.getMessage());
}
catch (PlaywrightException e) {
    return new ToolExecuteResult("Browser action failed: " + e.getMessage());
}

// 第 4 层：智能内容处理
try {
    SmartProcessResult processed = innerStorageService.processContent(...);
    return new ToolExecuteResult(processed.getSummary());
}
catch (Exception e) {
    log.warn("Failed to process content intelligently: {}", e.getMessage());
    return result; // 降级：返回原始结果
}
```

### 3. 资源清理模式

**Bash 的空清理**：
```java
@Override
public void cleanup(String planId) {
    log.info("Cleaned up resources for plan: {}", planId);
}
```

**Browser 的资源清理**：
```java
@Override
public void cleanup(String planId) {
    if (planId != null) {
        log.info("Cleaning up Chrome resources for plan: {}", planId);
        this.chromeDriverService.closeDriverForPlan(planId);
    }
}
```

**关键区别**：
- Bash：无需清理（命令执行完即结束）
- Browser：需要关闭浏览器实例（释放内存和端口）
