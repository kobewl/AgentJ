# 智能模板选择器 - 实现总结

> 完全摒弃硬编码规则，基于模板元数据+LLM的智能选择

---

## ✅ 核心改进

### 之前（硬编码规则）

```java
@PostConstruct
public void init() {
    // ❌ 20+ 条硬编码规则
    KEYWORD_MAPPING.put("网页", "guided-browser-research");
    KEYWORD_MAPPING.put("淘宝", "guided-browser-research");
    KEYWORD_MAPPING.put("京东", "guided-browser-research");
    KEYWORD_MAPPING.put("浏览器", "guided-browser-research");
    // ... 维护20+条规则 😰
}
```

### 现在（零硬编码）

```java
public String selectTemplate(String userInput) {
    // ✅ 动态加载所有模板元数据
    List<TemplateMetadata> templates = loadTemplateMetadata();

    // ✅ 让LLM理解用户任务和模板描述
    String prompt = buildIntelligentPrompt(userInput, templates);

    // ✅ LLM语义理解并选择
    return queryLLM(prompt);
}
```

## 💡 核心设计原则

### 1. 模板驱动（Template-Driven）

**所有"规则"都在模板中**:
```json
{
  "description": "使用浏览器工具完成网页信息收集和分析",
  "suitableFor": ["网页调研", "价格对比", "信息收集"]
}
```

而不是在代码中:
```java
// ❌ 不要这样做
KEYWORD_MAPPING.put("网页", "guided-browser-research");
KEYWORD_MAPPING.put("价格", "guided-browser-research");
```

### 2. 动态发现（Dynamic Discovery）

每次调用时动态读取所有模板:
```java
List<String> templateIds = planTemplateService.getAllTemplateIds();
for (String templateId : templateIds) {
    // 读取并解析模板元数据
}
```

**好处**:
- ✅ 新模板自动生效
- ✅ 无需重启服务
- ✅ 支持热更新

### 3. 语义理解（Semantic Understanding）

不是简单的关键词匹配:
```java
// ❌ 之前
if (input.contains("淘宝")) {
    return "guided-browser-research";
}
```

而是LLM理解语义:
```
"帮我购买iPhone" → LLM理解"可能需要浏览器" → guided-browser-research
"网上买东西" → LLM理解"网购" → guided-browser-research
"比价" → LLM理解"需要查多个网站" → guided-browser-research
```
