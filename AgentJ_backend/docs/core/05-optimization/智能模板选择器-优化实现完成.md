### 1. TemplateSelector.java (重写)

**位置**: `src/main/java/com/wangliang/agentj/planning/service/TemplateSelector.java`

**核心改动**:

```java
@Service
public class TemplateSelector {

    // ✅ 配置化开关
    @Value("${template.selector.cache-enabled:true}")
    private boolean cacheEnabled;

    @Value("${template.selector.rule-matching-enabled:true}")
    private boolean ruleMatchingEnabled;

    // ✅ 模板元数据缓存（5分钟TTL）
    private volatile List<TemplateMetadata> cachedTemplates;
    private volatile long lastCacheTime = 0;

    // ✅ 选择结果缓存（30分钟TTL）
    private final Map<String, CacheEntry> selectionCache = new ConcurrentHashMap<>();

    // ✅ 启动预加载
    @PostConstruct
    public void init() {
        if (cacheEnabled) {
            refreshCache(); // 预加载模板元数据
        }
    }

    /**
     * 三阶段选择策略：
     * 1. 快速规则匹配 (~1ms)
     * 2. 缓存查找 (~0ms)
     * 3. LLM语义理解 (~500ms, 仅5%任务)
     */
    public String selectTemplate(String userInput) {
        // Stage 1: 规则匹配
        if (ruleMatchingEnabled) {
            String matched = matchByRules(userInput);
            if (matched != null) return matched;
        }

        // Stage 2: 缓存查找
        if (cacheEnabled) {
            String cached = getCachedSelection(userInput);
            if (cached != null) return cached;
        }

        // Stage 3: LLM调用（缓存结果供下次使用）
        String selected = queryLLM(prompt);
        if (cacheEnabled) {
            cacheSelection(userInput, selected);
        }
        return selected;
    }

    /**
     * 快速规则匹配（常见场景）
     */
    private String matchByRules(String userInput) {
        String input = userInput.toLowerCase();

        // URL检测（优先级最高）
        if (input.contains("http://") || input.contains("https://") ||
            input.contains(".com") || input.contains(".cn")) {
            return "guided-browser-research";
        }

        // 电商平台
        if (input.contains("淘宝") || input.contains("京东") ||
            input.contains("天猫") || input.contains("拼多多")) {
            return "guided-browser-research";
        }

        // 浏览器相关
        if (input.contains("网页") || input.contains("网站") ||
            input.contains("浏览器") || input.contains("搜索")) {
            return "guided-browser-research";
        }

        // 数据分析（需要多个关键词）
        boolean hasAnalysisKeyword = input.contains("分析") || input.contains("统计");
        boolean hasDataKeyword = input.contains("数据") || input.contains("excel") ||
                                 input.contains("csv") || input.contains("表格");
        if (hasAnalysisKeyword && hasDataKeyword) {
            return "guided-general";
        }

        return null; // 未匹配，让LLM处理
    }

    /**
     * 公共API：获取缓存统计信息
     */
    public Map<String, Object> getCacheStatistics() {
        Map<String, Object> stats = new ConcurrentHashMap<>();
        stats.put("templateCacheSize", cachedTemplates != null ? cachedTemplates.size() : 0);
        stats.put("templateCacheAge",
            cachedTemplates != null ? System.currentTimeMillis() - lastCacheTime : 0);
        stats.put("templateCacheValid",
            cachedTemplates != null &&
            (System.currentTimeMillis() - lastCacheTime) < TEMPLATE_CACHE_TTL);
        stats.put("selectionCacheSize", selectionCache.size());
        stats.put("cacheEnabled", cacheEnabled);
        stats.put("ruleMatchingEnabled", ruleMatchingEnabled);
        return stats;
    }

    /**
     * 公共API：清除所有缓存
     */
    public void clearCache() {
        cachedTemplates = null;
        lastCacheTime = 0;
        selectionCache.clear();
    }

    /**
     * 公共API：仅清除选择结果缓存
     */
    public void clearSelectionCache() {
        selectionCache.clear();
    }
}
```

## 🎯 关键技术点

### 1. 模板元数据缓存

**目的**: 避免每次都查询数据库

**实现**:
```java
private volatile List<TemplateMetadata> cachedTemplates;
private static final long TEMPLATE_CACHE_TTL = 5 * 60 * 1000; // 5分钟

private List<TemplateMetadata> loadTemplateMetadata() {
    // 检查缓存是否有效
    if (cachedTemplates != null &&
        (System.currentTimeMillis() - lastCacheTime) < TEMPLATE_CACHE_TTL) {
        return cachedTemplates; // 使用缓存
    }
    return refreshCache(); // 刷新缓存
}
```

**线程安全**:
- `volatile` 关键字确保多线程可见性
- `synchronized` 方法确保刷新时线程安全
- 双重检查锁模式避免重复刷新

---

### 2. 选择结果缓存

**目的**: 重复输入直接返回结果

**实现**:
```java
private final Map<String, CacheEntry> selectionCache = new ConcurrentHashMap<>();

private String getCachedSelection(String userInput) {
    String normalized = normalizeInput(userInput); // 规范化输入
    CacheEntry entry = selectionCache.get(normalized);

    if (entry != null) {
        long age = System.currentTimeMillis() - entry.timestamp;
        if (age < SELECTION_CACHE_TTL) {
            return entry.selectedTemplate; // 缓存命中
        }
    }

    return null; // 缓存未命中或过期
}
```

**线程安全**:
- `ConcurrentHashMap` 天然线程安全
- 无需额外同步

## 📞 问题排查

### 问题1: 启动时缓存加载失败

**症状**: 日志显示 "⚠️ 启动时预加载模板元数据失败"

**排查**:
1. 检查数据库连接是否正常
2. 检查 `PlanTemplateConfigService.getAllPlanTemplates()` 是否返回数据
3. 检查模板JSON文件是否有效

**解决**:
- 缓存会在首次使用时自动重试
- 修复数据库问题后，手动调用 `/api/plan-template/template-selector/clear-cache` 强制刷新

---

### 问题2: 缓存未命中率高

**症状**: 日志显示大量 "🤖 规则未匹配且缓存未命中，使用LLM选择"

**排查**:
1. 检查 `cache-enabled` 配置是否为true
2. 检查输入是否变化太大（规范化可能失效）
3. 查看缓存统计: `/api/plan-template/template-selector/stats`

**解决**:
- 增加更多规则匹配关键词
- 调整输入规范化逻辑
- 增加 `selection-cache-size`

---

### 问题3: 内存占用过高

**症状**: JVM内存占用持续增长

**排查**:
1. 查看 `selectionCacheSize` 是否过大
2. 检查是否有内存泄漏

**解决**:
- 减少 `selection-cache-size`
- 减少 `SELECTION_CACHE_TTL`
- 调用 `/api/plan-template/template-selector/clear-selection-cache` 释放内存
