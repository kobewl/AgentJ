# 更智能的模板选择方案 - 基于模板元数据+LLM

> 摒弃硬编码规则，让AI动态理解模板和用户任务

---

## 🎯 核心思想

### 问题：硬编码规则的缺点

```java
// ❌ 当前实现：硬编码规则
KEYWORD_MAPPING.put("网页", "guided-browser-research");
KEYWORD_MAPPING.put("淘宝", "guided-browser-research");
KEYWORD_MAPPING.put("数据", "guided-general");
// ... 20+ 条规则
```

**问题**:
- ❌ 维护成本高：每个新规则都要手动添加
- ❌ 覆盖有限：只能匹配预定义的关键词
- ❌ 不够智能：无法理解语义和上下文
- ❌ 扩展性差：新模板需要添加大量规则

---

## 🚀 新方案：基于模板元数据 + 语义匹配

### 核心思路

```
用户输入
    ↓
【阶段1: 读取所有模板元数据】
    ↓
    读取每个模板的:
    - description（描述）
    - suitableFor（适用场景）
    ↓
【阶段2: LLM语义匹配】
    ↓
    让LLM理解用户输入
    对比所有模板的描述和适用场景
    选择最匹配的
    ↓
【阶段3: 返回最合适的模板】
```

### 优势

| 维度 | 硬编码规则 | 新方案 |
|------|-----------|--------|
| **维护成本** | 每个规则手动添加 | 零维护 ✅ |
| **覆盖范围** | 预定义关键词 | 任意语义匹配 ✅ |
| **智能化** | 关键词匹配 | 语义理解 ✅ |
| **扩展性** | 新模板需加规则 | 新模板自动生效 ✅ |
| **准确性** | 依赖关键词质量 | LLM理解上下文 ✅ |

## 💻 实现方案

### 方案A: 完全基于LLM（推荐）

```java
@Service
public class IntelligentTemplateSelector {

    @Autowired
    private LlmService llmService;

    @Autowired
    private PlanTemplateService planTemplateService;

    @Autowired
    private ObjectMapper objectMapper;

    /**
     * 智能选择模板 - 基于LLM的语义理解
     *
     * @param userInput 用户输入
     * @return 最合适的模板ID
     */
    public String selectTemplate(String userInput) {
        if (userInput == null || userInput.trim().isEmpty()) {
            return "autonomous-default";
        }

        // 1. 获取所有可用模板的元数据
        List<TemplateMetadata> templates = loadTemplateMetadata();

        // 2. 构建LLM Prompt
        String prompt = buildSelectionPrompt(userInput, templates);

        // 3. 调用LLM进行语义匹配
        String selectedTemplate = queryLLM(prompt);

        // 4. 验证并返回
        if (isValidTemplate(selectedTemplate)) {
            log.info("🤖 AI selected template: {} for input: {}", selectedTemplate, userInput);
            return selectedTemplate;
        }

        return "autonomous-default"; // 默认
    }

    /**
     * 加载所有模板的元数据
     */
    private List<TemplateMetadata> loadTemplateMetadata() {
        List<TemplateMetadata> templates = new ArrayList<>();

        // 获取所有模板ID
        List<String> templateIds = planTemplateService.getAllTemplateIds();

        for (String templateId : templateIds) {
            // 读取模板JSON
            String planJson = planTemplateService.getLatestPlanVersion(templateId);

            // 解析元数据
            JsonNode root = objectMapper.readTree(planJson);

            TemplateMetadata metadata = new TemplateMetadata();
            metadata.setPlanTemplateId(templateId);
            metadata.setTitle(root.path("title").asText());
            metadata.setDescription(root.path("description").asText());

            // 解析 suitableFor（如果存在）
            JsonNode suitableForNode = root.path("suitableFor");
            if (suitableForNode.isArray()) {
                List<String> suitableFor = new ArrayList<>();
                for (JsonNode node : suitableForNode) {
                    suitableFor.add(node.asText());
                }
                metadata.setSuitableFor(suitableFor);
            }

            // 解析 executionMode
            metadata.setExecutionMode(root.path("executionMode").asText());

            templates.add(metadata);
        }

        return templates;
    }

    /**
     * 构建LLM Prompt
     */
    private String buildSelectionPrompt(String userInput, List<TemplateMetadata> templates) {
        StringBuilder prompt = new StringBuilder();

        prompt.append("你是一个智能任务分类助手。根据用户任务，选择最合适的执行模板。\n\n");

        prompt.append("【可用模板列表】\n");
        for (TemplateMetadata template : templates) {
            prompt.append(String.format(
                "模板ID: %s\n" +
                "标题: %s\n" +
                "描述: %s\n" +
                "适用场景: %s\n" +
                "执行模式: %s\n\n",
                template.getPlanTemplateId(),
                template.getTitle(),
                template.getDescription(),
                template.getSuitableFor() != null ? String.join(", ", template.getSuitableFor()) : "通用任务",
                template.getExecutionMode()
            ));
        }

        prompt.append("【用户任务】\n");
        prompt.append(userInput);
        prompt.append("\n\n");

        prompt.append("请分析用户任务，从上述模板中选择最合适的一个。\n");
        prompt.append("只需返回模板的 planTemplateId，不要返回其他内容。\n");

        return prompt.toString();
    }

    /**
     * 查询LLM进行选择
     */
    private String queryLLM(String prompt) {
        try {
            ChatResponse response = llmService.chat(prompt, null);
            String result = response.getResult().getOutput().getText().trim();

            // 清理结果
            result = result.replaceAll("[\"'`]", "").trim();

            return result;
        } catch (Exception e) {
            log.warn("LLM selection failed, using default", e);
            return "autonomous-default";
        }
    }

    /**
     * 模板元数据
     */
    @Data
    private static class TemplateMetadata {
        private String planTemplateId;
        private String title;
        private String description;
        private List<String> suitableFor;
        private String executionMode;
    }
}
```

## 🎨 更优雅的实现：语义向量匹配

### 方案B: 基于Embedding的语义相似度

```java
@Service
public class SemanticTemplateSelector {

    @Autowired
    private EmbeddingService embeddingService;

    /**
     * 使用语义相似度选择模板
     */
    public String selectTemplate(String userInput) {
        // 1. 获取用户输入的向量
        float[] userEmbedding = embeddingService.embed(userInput);

        // 2. 计算与每个模板的相似度
        String bestTemplate = null;
        float maxSimilarity = 0;

        for (TemplateMetadata template : templates) {
            // 拼接描述和适用场景
            String templateText = template.getDescription() + " " +
                                   String.join(" ", template.getSuitableFor());

            // 计算模板向量
            float[] templateEmbedding = embeddingService.embed(templateText);

            // 计算余弦相似度
            float similarity = cosineSimilarity(userEmbedding, templateEmbedding);

            if (similarity > maxSimilarity) {
                maxSimilarity = similarity;
                bestTemplate = template.getPlanTemplateId();
            }
        }

        // 3. 返回最相似的模板
        if (maxSimilarity > 0.7) {  // 相似度阈值
            return bestTemplate;
        }

        return "autonomous-default";
    }

    /**
     * 余弦相似度计算
     */
    private float cosineSimilarity(float[] vec1, float[] vec2) {
        float dotProduct = 0;
        float norm1 = 0;
        float norm2 = 0;

        for (int i = 0; i < vec1.length; i++) {
            dotProduct += vec1[i] * vec2[i];
            norm1 += vec1[i] * vec1[i];
            norm2 += vec2[i] * vec2[i];
        }

        return (float) (dotProduct / (Math.sqrt(norm1) * Math.sqrt(norm2)));
    }
}
```

## 🔥 终极方案：混合智能选择器

结合多种策略，逐步提升：

```java
@Service
public class HybridIntelligentSelector {

    @Autowired
    private LlmService llmService;

    @Autowired
    private EmbeddingService embeddingService;

    /**
     * 多阶段智能选择
     */
    public String selectTemplate(String userInput) {
        // 阶段1: 快速语义匹配（基于Embedding）
        String selected = selectByEmbedding(userInput);
        if (selected != null) {
            log.info("🎯 Selected by embedding: {}", selected);
            return selected;
        }

        // 阶段2: LLM深度理解
        selected = selectByLLM(userInput);
        log.info("🤖 Selected by LLM: {}", selected);
        return selected;
    }

    /**
     * 基于Embedding的快速匹配
     */
    private String selectByEmbedding(String userInput) {
        float[] userEmbedding = embeddingService.embed(userInput);

        float maxSimilarity = 0;
        String bestTemplate = null;

        for (TemplateMetadata template : templates) {
            float similarity = calculateSimilarity(userEmbedding, template);

            if (similarity > maxSimilarity) {
                maxSimilarity = similarity;
                bestTemplate = template.getPlanTemplateId();
            }
        }

        // 相似度 > 0.75 才返回，否则用LLM
        return maxSimilarity > 0.75 ? bestTemplate : null;
    }

    /**
     * LLM深度理解（作为兜底）
     */
    private String selectByLLM(String userInput) {
        String prompt = buildPrompt(userInput, templates);
        return queryLLM(prompt);
    }
}

## 💡 完整实现代码

让我为你实现一个完全基于模板元数据+LLM的智能选择器：

```java
package com.wangliang.agentj.planning.service;

import com.fasterxml.jackson.databind.JsonNode;
import com.fasterxml.jackson.databind.ObjectMapper;
import com.wangliang.agentj.llm.LlmService;
import com.wangliang.agentj.planning.service.PlanTemplateService;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.ai.chat.model.ChatResponse;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Service;

import java.util.ArrayList;
import java.util.List;

/**
 * 智能模板选择器 - 基于模板元数据和LLM的语义理解
 *
 * 核心设计原则:
 * 1. 无硬编码规则: 所有规则来自模板元数据
 * 2. LLM驱动: 由LLM理解用户任务和模板描述
 * 3. 动态发现: 自动发现所有可用模板
 * 4. 可解释性: LLM可以解释选择原因
 */
@Service
public class IntelligentTemplateSelector {

    private static final Logger log = LoggerFactory.getLogger(IntelligentTemplateSelector.class);

    @Autowired
    private LlmService llmService;

    @Autowired
    private PlanTemplateService planTemplateService;

    @Autowired
    private ObjectMapper objectMapper;

    @Value("${template.selector.default-template:autonomous-default}")
    private String defaultTemplate;

    /**
     * 智能选择最合适的模板
     *
     * @param userInput 用户任务描述
     * @return 模板ID
     */
    public String selectTemplate(String userInput) {
        if (userInput == null || userInput.trim().isEmpty()) {
            return defaultTemplate;
        }

        try {
            // 1. 动态加载所有模板元数据
            List<TemplateMetadata> templates = loadTemplateMetadata();

            if (templates.isEmpty()) {
                log.warn("No templates found, using default");
                return defaultTemplate;
            }

            // 2. 构建智能Prompt
            String prompt = buildIntelligentPrompt(userInput, templates);

            // 3. LLM语义理解并选择
            String selectedTemplate = queryLLM(prompt);

            // 4. 验证并返回
            if (isValidTemplate(selectedTemplate, templates)) {
                log.info("🤖 AI selected template: {} for input: {}", selectedTemplate, truncate(userInput));
                return selectedTemplate;
            } else {
                log.warn("LLM returned invalid template: {}, using default", selectedTemplate);
                return defaultTemplate;
            }

        } catch (Exception e) {
            log.error("Template selection failed, using default", e);
            return defaultTemplate;
        }
    }

    /**
     * 动态加载所有模板的元数据
     *
     * @return 模板元数据列表
     */
    private List<TemplateMetadata> loadTemplateMetadata() {
        List<TemplateMetadata> templates = new ArrayList<>();

        try {
            // 获取所有模板ID
            List<String> templateIds = planTemplateService.getAllTemplateIds();

            for (String templateId : templateIds) {
                try {
                    // 读取模板JSON
                    String planJson = planTemplateService.getLatestPlanVersion(templateId);
                    if (planJson == null) {
                        continue;
                    }

                    // 解析JSON
                    JsonNode root = objectMapper.readTree(planJson);

                    TemplateMetadata metadata = new TemplateMetadata();
                    metadata.setPlanTemplateId(templateId);
                    metadata.setTitle(root.path("title").asText(""));

                    // 读取description
                    JsonNode descNode = root.path("description");
                    metadata.setDescription(descNode.isMissingNode() ? "" : descNode.asText());

                    // 读取suitableFor
                    JsonNode suitableForNode = root.path("suitableFor");
                    if (suitableForNode.isArray()) {
                        List<String> suitableFor = new ArrayList<>();
                        for (JsonNode node : suitableForNode) {
                            suitableFor.add(node.asText());
                        }
                        metadata.setSuitableFor(suitableFor);
                    }

                    // 读取executionMode
                    JsonNode modeNode = root.path("executionMode");
                    metadata.setExecutionMode(modeNode.isMissingNode() ? "unknown" : modeNode.asText());

                    templates.add(metadata);

                } catch (Exception e) {
                    log.warn("Failed to load metadata for template: {}", templateId, e);
                }
            }

            log.info("Loaded {} template(s) for intelligent selection", templates.size());

        } catch (Exception e) {
            log.error("Failed to load template metadata", e);
        }

        return templates;
    }

    /**
     * 构建智能Prompt - 让LLM理解用户任务和模板
     */
    private String buildIntelligentPrompt(String userInput, List<TemplateMetadata> templates) {
        StringBuilder prompt = new StringBuilder();

        prompt.append("# 角色\n");
        prompt.append("你是一个智能任务分类助手，擅长理解用户意图并选择最合适的执行模板。\n\n");

        prompt.append("# 可用模板\n");
        prompt.append("以下是系统中的所有可用模板及其详细信息：\n\n");

        for (TemplateMetadata template : templates) {
            prompt.append(String.format(
                "## 模板: %s\n" +
                "- 标题: %s\n" +
                "- 描述: %s\n" +
                "- 执行模式: %s\n",
                template.getPlanTemplateId(),
                template.getTitle(),
                template.getDescription(),
                template.getExecutionMode()
            ));

            if (template.getSuitableFor() != null && !template.getSuitableFor().isEmpty()) {
                prompt.append(String.format(
                    "- 适用场景: %s\n",
                    String.join("、", template.getSuitableFor())
                ));
            }

            prompt.append("\n");
        }

        prompt.append("# 用户任务\n");
        prompt.append("```\n");
        prompt.append(userInput);
        prompt.append("\n```\n\n");

        prompt.append("# 任务\n");
        prompt.append("请分析上述用户任务，从可用模板中选择**最合适**的一个。\n\n");
        prompt.append("选择标准:\n");
        prompt.append("1. 任务是否在模板的适用场景中\n");
        prompt.append("2. 任务是否需要模板描述中的功能\n");
        prompt.append("3. 任务的复杂度和不确定性与执行模式是否匹配\n\n");

        prompt.append("# 输出格式\n");
        prompt.append("请只返回模板的 planTemplateId，不要包含任何其他内容或解释。\n");
        prompt.append("例如: guided-browser-research\n");

        return prompt.toString();
    }

    /**
     * 查询LLM进行选择
     */
    private String queryLLM(String prompt) {
        try {
            ChatResponse response = llmService.chat(prompt, null);

            if (response == null || response.getResult() == null ||
                response.getResult().getOutput() == null) {
                return defaultTemplate;
            }

            String result = response.getResult().getOutput().getText().trim();

            // 清理结果
            result = cleanResult(result);

            return result.isEmpty() ? defaultTemplate : result;

        } catch (Exception e) {
            log.warn("LLM query failed", e);
            return defaultTemplate;
        }
    }

    /**
     * 清理LLM返回结果
     */
    private String cleanResult(String result) {
        if (result == null || result.isEmpty()) {
            return "";
        }

        // 移除markdown代码块
        result = result.replaceAll("```", "").trim();

        // 移除引号
        result = result.replaceAll("[\"'`]", "").trim();

        // 提取第一行（防止LLM返回额外解释）
        int newlineIndex = result.indexOf('\n');
        if (newlineIndex > 0) {
            result = result.substring(0, newlineIndex).trim();
        }

        return result;
    }

    /**
     * 验证模板ID是否有效
     */
    private boolean isValidTemplate(String templateId, List<TemplateMetadata> templates) {
        if (templateId == null || templateId.isEmpty()) {
            return false;
        }

        return templates.stream()
            .anyMatch(t -> templateId.equals(t.getPlanTemplateId()));
    }

    /**
     * 截断字符串用于日志
     */
    private String truncate(String str) {
        if (str == null) {
            return "null";
        }
        return str.length() <= 100 ? str : str.substring(0, 100) + "...";
    }

    /**
     * 模板元数据
     */
    @Data
    private static class TemplateMetadata {
        private String planTemplateId;
        private String title;
        private String description;
        private List<String> suitableFor;
        private String executionMode;
    }
}
```
