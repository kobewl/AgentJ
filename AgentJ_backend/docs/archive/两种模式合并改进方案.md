# 两种模式合并改进方案

## 🎯 目标

将当前的三种模式简化为两种：
- **autonomous（完全自主）** - 所有工具，AI完全自主
- **guided（模板引导）** - 工具可限制，步骤有框架

---

## 📋 当前状态

### 三种模式对比

| 模板 | planTemplateId | selectedToolKeys | 步骤 | PlanDraftingService |
|------|----------------|------------------|------|---------------------|
| default_user_input | default-plan-id-001000222 | 未定义 | 1步 | ❌ 不触发 |
| auto_general_plan | auto-general-plan | 未定义 | 3步框架 | ✅ 触发 |
| auto_browser_plan | auto-browser-plan | 4个工具 | 4步框架 | ✅ 触发 |

**问题**: default 和 auto-general 功能重叠，都是所有工具可用

---

## 🚀 改进方案

### 方案设计

#### 1. 添加 executionMode 字段

**定义两种执行模式**:
```java
public enum ExecutionMode {
    AUTONOMOUS,  // 完全自主：所有工具，步骤由AI决定
    GUIDED       // 模板引导：工具可限制，步骤有框架
}
```

#### 2. 模板结构

**Autonomous 模式**:
```json
{
  "planTemplateId": "autonomous-default",
  "title": "完全自主模式",
  "executionMode": "autonomous",
  "enableAutoPlanning": false,
  "steps": [
    {
      "stepRequirement": "<<userRequirement>>",
      "agentName": "ConfigurableDynaAgent",
      "selectedToolKeys": []
    }
  ]
}
```

**Guided 模式**:
```json
{
  "planTemplateId": "guided-browser-research",
  "title": "浏览器调研计划",
  "executionMode": "guided",
  "enableAutoPlanning": true,
  "steps": [
    {
      "stepRequirement": "[BROWSER_AGENT] 解析任务并生成浏览计划：<<task>>",
      "agentName": "ConfigurableDynaAgent",
      "selectedToolKeys": ["browser_use", "extract_content", "terminate"]
    }
  ]
}
```

#### 3. 执行逻辑

**行为判定表**:

| executionMode | enableAutoPlanning | selectedToolKeys | 行为 |
|--------------|-------------------|------------------|------|
| autonomous | false | [] | 完全自主，所有工具，不触发PlanDraftingService |
| guided | true | [tool1, tool2] | 模板引导，限制工具，触发PlanDraftingService |
| guided | false | [tool1, tool2] | 模板引导，限制工具，不触发PlanDraftingService（静态步骤） |

### 改进2: ExecutionStep 添加字段

**文件位置**: `src/main/java/com/wangliang/agentj/runtime/entity/vo/ExecutionStep.java`

**添加字段**:
```java
public class ExecutionStep {
    // 现有字段...

    /**
     * 执行模式：autonomous 或 guided
     */
    private String executionMode;

    /**
     * 是否启用自动规划
     */
    private Boolean enableAutoPlanning;

    // Getters and Setters
    public String getExecutionMode() {
        return executionMode;
    }

    public void setExecutionMode(String executionMode) {
        this.executionMode = executionMode;
    }

    public Boolean getEnableAutoPlanning() {
        return enableAutoPlanning;
    }

    public void setEnableAutoPlanning(Boolean enableAutoPlanning) {
        this.enableAutoPlanning = enableAutoPlanning;
    }
}
```

### 改进3: 修改 LynxeController

**文件位置**: `src/main/java/com/wangliang/agentj/runtime/controller/LynxeController.java`

**修改前** (第1071行):
```java
if (!planTemplateId.startsWith("auto-")) {
    return;
}
```

**修改后**:
```java
// 读取模板配置中的 enableAutoPlanning 字段
Boolean enableAutoPlanning = plan.getEnableAutoPlanning();
if (plan.getEnableAutoPlanning() == null || !plan.getEnableAutoPlanning()) {
    return;
}

// 根据 executionMode 决定是否执行
String executionMode = plan.getExecutionMode();
if ("autonomous".equals(executionMode)) {
    logger.info("Using autonomous mode for planTemplateId: {}", planTemplateId);
    return; // 自主模式不触发自动规划
}

// 只有 guided 模式且 enableAutoPlanning=true 才触发
if (!"guided".equals(executionMode)) {
    logger.warn("Unknown execution mode: {}, skipping auto planning", executionMode);
    return;
}
```

## 🎨 最终效果

### 两种模式对比

| 维度 | Autonomous（完全自主） | Guided（模板引导） |
|------|------------------------|-------------------|
| **planTemplateId** | autonomous-default | guided-* |
| **executionMode** | autonomous | guided |
| **工具权限** | 所有工具（30+） | 可限制（selectedToolKeys） |
| **步骤生成** | AI完全自主 | 有框架 + 可自动生成 |
| **PlanDraftingService** | ❌ 不触发 | ✅ 可触发 |
| **适用场景** | 探索性、复杂任务 | 标准化、重复性任务 |
| **成本** | 较高 | 较低 |
| **可控性** | 低 | 高 |

### 用户选择界面

```

├──────────────────────────────────────────────────────────┤

├──────────────────────────────────────────────────────────┤
│ autonomous-default   │ 完全自主模式  │ 完全自主  │ 通用    │
│ guided-browser       │ 浏览器调研    │ 模板引导  │ 网页调研 │
```

## 📝 使用示例

### 示例1: 探索性任务（使用 autonomous）

**用户输入**: "帮我分析一下这个复杂的问题并给出建议"

**选择模板**: autonomous-default

**执行流程**:
```
1. 直接使用用户输入作为步骤
2. AI拥有所有工具
3. AI自主决定如何执行
4. 可能调用任意工具组合
```

### 示例2: 网页调研（使用 guided）

**用户输入**: "帮我在淘宝上查iPhone 15的价格"

**选择模板**: guided-browser-research

**执行流程**:
```
1. PlanDraftingService 生成3-6步
2. 只能使用 browser_use 等指定工具
3. 按照框架执行
4. 成本更低，更可控
```

## ✅ 改进优势

1. **清晰明确**: 两种模式边界清晰，不再混淆
2. **易于理解**: 新用户一眼就能看出区别
3. **灵活配置**: 通过字段组合实现不同行为
4. **扩展性好**: 添加新模板不需要修改核心代码
5. **向后兼容**: 旧模板可以通过添加字段升级
