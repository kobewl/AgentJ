## 📚 可以学到的核心知识点

### 1. Spring AI Function Calling 机制

#### 1.1 什么是 Function Calling？

**Function Calling** 是 OpenAI 提供的一种协议，让 LLM 能够调用外部工具。

**工作流程**：
```
用户请求 → LLM 分析 → 选择工具 → 返回 ToolCall → 系统执行工具 → 返回结果 → LLM 生成回答
```

**实际示例**：
```
用户："查询所有管理员用户"
    ↓
LLM 分析：需要查询数据库
    ↓
LLM 返回 ToolCall：
{
  "name": "database_read_use",
  "arguments": {
    "action": "execute_read_sql",
    "query": "SELECT * FROM users WHERE role = 'admin'"
  }
}
    ↓
系统执行 SQL 并返回结果
    ↓
LLM 根据结果回答用户
```

#### 1.2 Spring AI 工具接口

**Spring AI 的 ToolCallback**：
```java
ToolCallback callback = ToolCallback.builder()
    .name("database_read_use")
    .description("Execute read-only SQL queries...")
    .inputType(DatabaseRequest.class)
    .function("database_read_use", toolInstance)
    .build();
```

**AgentJ 的适配接口**：
```java
public interface ToolCallBiFunctionDef<I>
    extends BiFunction<I, ToolContext, ToolExecuteResult> {

    String getName();           // 工具名称
    String getDescription();    // 工具描述
    String getParameters();     // JSON Schema 参数定义
    Class<I> getInputType();    // 输入类型

    // 工具执行
    ToolExecuteResult apply(I input, ToolContext context);
}
```

### 2. 数据库工具架构设计

#### 2.1 读写分离设计

**为什么分离？**
- **安全**：防止误操作导致数据丢失
- **权限控制**：只读工具只能查询
- **审计**：写操作可以单独记录

**架构图**：
```
┌─────────────────────────────────────────┐
│         DatabaseReadTool (只读)          │
│  - execute_read_sql: 只能 SELECT        │
│  - get_table_name: 获取表名             │
│  - execute_read_sql_to_json_file: 导出  │
└─────────────────────────────────────────┘
                  ↓
            安全验证层
                  ↓
┌─────────────────────────────────────────┐
│        DatabaseWriteTool (写操作)         │
│  - execute_write_sql: INSERT/UPDATE/DELETE │
└─────────────────────────────────────────┘
```

**代码实现**：
```java
// DatabaseReadTool - 强制安全检查
@Override
public ToolExecuteResult run(DatabaseRequest request) {
    String action = request.getAction();
    String query = request.getQuery();

    // 只读模式：强制检查必须是 SELECT
    if ("execute_read_sql".equals(action)) {
        if (query != null && !query.trim().toUpperCase().startsWith("SELECT")) {
            return new ToolExecuteResult(
                "Only SELECT queries are allowed in read-only mode"
            );
        }
    }

    return executeSql(request);
}
```

#### 2.2 Action 模式设计

**为什么用 Action 模式？**
- 一个工具支持多种操作
- 代码结构清晰，易于扩展
- 便于权限控制

**Action 分发**：
```java
@Override
public ToolExecuteResult run(DatabaseRequest request) {
    String action = request.getAction();

    switch (action) {
        case "execute_read_sql":
            return new ExecuteSqlAction().execute(request, dataSourceService);
        case "get_table_name":
            return new GetTableNameAction().execute(request, dataSourceService);
        case "execute_read_sql_to_json_file":
            return new ExecuteSqlToJsonFileAction().execute(request, dataSourceService);
        default:
            return new ToolExecuteResult("Unknown action: " + action);
    }
}
```

**支持的 Action**：

| Action | 功能 | 安全检查 |
|--------|------|----------|
| `execute_read_sql` | 执行 SELECT 查询 | ✅ 强制 SELECT |
| `execute_write_sql` | 执行 INSERT/UPDATE/DELETE | - |
| `get_table_name` | 获取所有表名 | - |
| `get_table_meta` | 获取表结构 | - |
| `get_table_index` | 获取表索引 | - |
| `execute_read_sql_to_json_file` | 查询并导出 JSON | ✅ 强制 SELECT |

### 3. SQL 注入防护

#### 3.1 问题：SQL 注入攻击

**危险代码**：
```java
// ❌ 容易被 SQL 注入
String query = "SELECT * FROM users WHERE name = '" + userName + "'";
Statement stmt = conn.createStatement();
stmt.execute(query);

// 如果 userName = "admin' OR '1'='1"
// 实际执行的 SQL：
// SELECT * FROM users WHERE name = 'admin' OR '1'='1'
// → 会返回所有用户数据！
```

#### 3.2 解决方案：PreparedStatement

**安全代码**：
```java
// ✅ 使用 PreparedStatement 防止注入
String query = "SELECT * FROM users WHERE name = ?";
PreparedStatement pstmt = conn.prepareStatement(query);
pstmt.setString(1, userName);  // 参数化
ResultSet rs = pstmt.executeQuery();

// 无论 userName 是什么，都会被当作字符串处理
// 不会改变 SQL 结构
```

#### 3.3 完整实现

**参数验证**：
```java
private ToolExecuteResult executePreparedStatement(
        String query,
        List<Object> parameters,
        String datasourceName,
        DataSourceService dataSourceService) {

    // 1. 验证参数数量匹配
    int placeholderCount = countPlaceholders(query);
    if (placeholderCount != parameters.size()) {
        return new ToolExecuteResult(String.format(
            "Parameter count mismatch: SQL has %d placeholders, but %d parameters provided",
            placeholderCount, parameters.size()
        ));
    }

    // 2. 使用 PreparedStatement
    try (Connection conn = getConnection(datasourceName, dataSourceService);
         PreparedStatement pstmt = conn.prepareStatement(query)) {

        // 3. 设置参数
        for (int i = 0; i < parameters.size(); i++) {
            Object param = parameters.get(i);
            if (param == null) {
                pstmt.setNull(i + 1, Types.NULL);
            } else {
                pstmt.setObject(i + 1, param);
            }
        }

        // 4. 执行查询
        ResultSet rs = pstmt.executeQuery();
        return formatResultSet(rs);

    } catch (SQLException e) {
        return new ToolExecuteResult("SQL execution failed: " + e.getMessage());
    }
}

// 统计占位符数量
private int countPlaceholders(String query) {
    int count = 0;
    for (int i = 0; i < query.length(); i++) {
        if (query.charAt(i) == '?') {
            count++;
        }
    }
    return count;
}
```

**参数化查询示例**：
```json
// AI 调用
{
  "action": "execute_read_sql",
  "query": "SELECT * FROM users WHERE role = ? AND status = ?",
  "parameters": ["admin", "active"]
}

// 执行过程
1. 检测到 2 个占位符 (?)
2. parameters 有 2 个元素 → 验证通过
3. pstmt.setString(1, "admin")
4. pstmt.setString(2, "active")
5. 执行：SELECT * FROM users WHERE role = 'admin' AND status = 'active'
```

#### 4.2 DataSourceService 设计

**数据源存储**：
```java
@Service
public class DataSourceService {

    // 数据源映射
    private final Map<String, DataSource> dataSourceMap = new ConcurrentHashMap<>();

    // 数据源类型映射
    private final Map<String, String> dataSourceTypeMap = new ConcurrentHashMap<>();

    // 添加数据源
    public void addDataSource(String name, String url, String username,
                             String password, String driverClassName, String type) {
        DriverManagerDataSource dataSource = new DriverManagerDataSource();
        dataSource.setUrl(url);
        dataSource.setUsername(username);
        dataSource.setPassword(password);
        dataSource.setDriverClassName(driverClassName);

        dataSourceMap.put(name, dataSource);
        dataSourceTypeMap.put(name, type);

        log.info("Added datasource '{}' with type: {}", name, type);
    }

    // 获取连接（指定数据源）
    public Connection getConnection(String datasourceName) throws SQLException {
        DataSource dataSource = dataSourceMap.get(datasourceName);
        if (dataSource == null) {
            throw new SQLException("DataSource '" + datasourceName + "' not found");
        }
        return dataSource.getConnection();
    }

    // 获取连接（默认数据源）
    public Connection getConnection() throws SQLException {
        Set<String> names = getDataSourceNames();
        if (names.isEmpty()) {
            throw new SQLException("No datasources available");
        }
        return getConnection(names.iterator().next());
    }
}
```

**使用示例**：
```java
// 查询主库

request1.setAction("execute_read_sql");
request1.setQuery("SELECT * FROM users");
request1.setDatasourceName("primary_db");

// 查询从库

request2.setAction("execute_read_sql");
request2.setQuery("SELECT * FROM logs");
```

**作用**：让 LLM 准确感知工具状态，避免盲目调用

#### 5.2 DatabaseReadTool 的环境数据

**实现**：
```java
@Override
public String getCurrentToolStateString() {
    try {
        Map<String, String> datasourceInfo =
            dataSourceService.getAllDatasourceInfo();

        StringBuilder stateBuilder = new StringBuilder();
        stateBuilder.append("\n=== Database Read Tool Current State ===\n");

        if (datasourceInfo.isEmpty()) {
            stateBuilder.append("No datasources configured or available.\n");
        } else {
            stateBuilder.append("Available datasources:\n");
            for (Map.Entry<String, String> entry : datasourceInfo.entrySet()) {
                stateBuilder.append(String.format(
                    "  - %s (%s)\n",
                    entry.getKey(),   // 数据源名称
                    entry.getValue()   // 数据源类型
                ));
            }
        }

        stateBuilder.append("\n=== End Database Read Tool State ===\n");
        return stateBuilder.toString();
    } catch (Exception e) {
        return "Error retrieving database tool state";
    }
}
```

### 6. 结果集格式化

#### 6.1 Markdown 表格生成

**实现**：
```java
private String formatResultSet(ResultSet rs) throws SQLException {
    int columnCount = rs.getMetaData().getColumnCount();

    // 收集列名
    List<String> columnNames = new ArrayList<>();
    for (int i = 1; i <= columnCount; i++) {
        columnNames.add(rs.getMetaData().getColumnName(i));
    }

    // 收集数据行
    List<List<String>> rows = new ArrayList<>();
    while (rs.next()) {
        List<String> row = new ArrayList<>();
        for (int i = 1; i <= columnCount; i++) {
            Object val = rs.getObject(i);
            String cellValue = (val == null) ? "NULL" : val.toString();
            row.add(escapeMarkdownTableCell(cellValue));
        }
        rows.add(row);
    }

    // 构建 Markdown 表格
    StringBuilder table = new StringBuilder();

    // 表头
    table.append("| ");
    for (String col : columnNames) {
        table.append(col).append(" | ");
    }
    table.append("\n");

    // 分隔线
    table.append("| ");
    for (int i = 0; i < columnNames.size(); i++) {
        table.append("--- | ");
    }
    table.append("\n");

    // 数据行
    for (List<String> row : rows) {
        table.append("| ");
        for (String cell : row) {
            table.append(cell).append(" | ");
        }
        table.append("\n");
    }

    return table.toString();
}
```

**输出示例**：
```
| id | name | email | role |
| --- | --- | --- | --- |
| 1 | 张三 | zhangsan@example.com | admin |
| 2 | 李四 | lisi@example.com | user |
```

#### 6.2 单元格转义

**为什么需要转义？**
```
原始数据：name = "王|李"
直接输出：| 王|李 |  ← Markdown 表格会错位
转义后：| 王\|李 |  ← 正确显示
```

**转义实现**：
```java
private String escapeMarkdownTableCell(String cell) {
    if (cell == null) {
        return "";
    }
    // 转义管道符和换行符
    return cell.replace("|", "\\|")
               .replace("\n", "\\n")
               .replace("\r", "\\r");
}
```

```java
public class PlanningFactory {

    private final Map<String, ToolCallBackContext> toolCallbackMap;

    // Spring 自动注入所有 ToolCallBiFunctionDef
    public PlanningFactory(List<ToolCallBiFunctionDef<?>> tools) {
        for (ToolCallBiFunctionDef<?> tool : tools) {
            String toolKey = tool.getName();
            toolCallbackMap.put(toolKey, new ToolCallBackContext(tool));
            log.info("Registered tool: {}", toolKey);
        }
    }
}
```

#### 7.2 工具发现流程

```
DynamicAgent 需要工具
    ↓
调用 collectAvailableTools()
    ↓
从 PlanningFactory 获取所有工具
    ↓
过滤 isSelectable() = true 的工具
    ↓
创建 Spring AI ToolCallback
    ↓
添加到 LLM Prompt 中
```

**代码**：
```java
protected List<ToolCallback> collectAvailableTools() {
    List<ToolCallback> callbacks = new ArrayList<>();

    Map<String, ToolCallBackContext> allTools =
        toolCallbackProvider.getToolCallBackContext();

    for (ToolCallBackContext context : allTools.values()) {
        ToolCallBiFunctionDef<?> tool = context.getFunctionInstance();

        if (tool.isSelectable()) {
            ToolCallback callback = ToolCallback.builder()
                .name(tool.getName())
                .description(tool.getDescription())
                .inputType(tool.getInputType())
                .function(tool.getName(), tool)
                .build();

            callbacks.add(callback);
        }
    }

    return callbacks;
}
```

### 阶段 3：动手实践（3-5 天）

**实践项目 1：数据统计工具**

实现一个统计表行数的工具：
```java
@Component
public class DatabaseCountTool extends AbstractBaseTool<CountRequest> {

    @Override
    public ToolExecuteResult run(CountRequest request) {
        String tableName = request.getTableName();
        String whereClause = request.getWhereClause();

        // 防止 SQL 注入：只允许字母、数字、下划线
        if (!tableName.matches("^[a-zA-Z0-9_]+$")) {
            return new ToolExecuteResult("Invalid table name");
        }

        // 构建 SQL
        String sql = "SELECT COUNT(*) as row_count FROM " + tableName;
        if (whereClause != null) {
            sql += " WHERE " + whereClause;
```

## 📝 面试常见问题

### Q1：如何防止 SQL 注入？

**回答要点**：
1. **使用 PreparedStatement**：参数化查询
2. **输入验证**：检查表名、字段名的合法性
3. **权限控制**：只读工具只允许 SELECT
4. **参数数量验证**：确保占位符数量与参数数量匹配

**代码示例**：
```java
// 1. 参数化查询
PreparedStatement pstmt = conn.prepareStatement(query);
pstmt.setString(1, userName);

// 2. 输入验证
if (!tableName.matches("^[a-zA-Z0-9_]+$")) {
    throw new IllegalArgumentException("Invalid table name");
}

// 3. 权限检查
if (isReadOnlyMode && !query.toUpperCase().startsWith("SELECT")) {
    throw new SecurityException("Only SELECT allowed in read-only mode");
}
```

### Q2：如何支持多数据源？

**回答要点**：
1. **数据源注册**：使用 Map 存储多个数据源
2. **连接获取**：根据名称获取对应数据源的连接
3. **默认数据源**：未指定时使用第一个
4. **状态管理**：维护每个数据源的类型和状态

```java
// 数据源注册
dataSourceService.addDataSource(

// 获取连接
Connection conn = dataSourceService.getConnection("primary_db");

// 环境数据

    dataSourceService.getAllDatasourceInfo();
```

### Q3：AI 如何调用数据库工具？

**回答要点**：
1. **工具注册**：@Component + PlanningFactory
2. **工具发现**：collectAvailableTools()
3. **Prompt 构建**：将工具信息注入 Prompt
4. **AI 决策**：LLM 选择工具并构造参数
5. **工具执行**：ToolCallingManager 执行工具
6. **结果返回**：格式化后返回给 AI

**流程图**：
```
用户请求 → DynamicAgent.think()
    → 收集工具环境数据
    → 构建 Prompt（包含工具列表）
    → 调用 LLM
    → LLM 返回 ToolCall
    → DynamicAgent.act()
    → 执行工具
    → 返回结果
```

### Q4：工具环境数据的作用是什么？

**回答要点**：
1. **解决信息不对称**：让 LLM 准确感知工具状态
2. **提高调用准确率**：避免盲目调用失败
3. **实时状态同步**：每次思考前收集最新状态
4. **上下文注入**：将状态注入到 Prompt 中

**示例**：
```
没有环境数据：
LLM："有数据库吗？" → 尝试调用 → 失败（没有数据源）

有环境数据：
LLM 看到："Available datasources: primary_db (MySQL)"
→ 正确调用 → 成功
```

### Q5：如何实现工具的读写分离？

**回答要点**：
1. **两个工具**：DatabaseReadTool + DatabaseWriteTool
2. **权限控制**：ReadTool 强制检查 SELECT
3. **Action 分发**：不同的 action 执行不同操作
4. **安全验证**：在 run() 方法中验证

**代码示例**：
```java
// DatabaseReadTool
if ("execute_read_sql".equals(action)) {
    if (!query.toUpperCase().startsWith("SELECT")) {
        return error("Only SELECT queries allowed");
    }
}

// DatabaseWriteTool
if ("execute_write_sql".equals(action)) {
    // 允许 INSERT、UPDATE、DELETE
    return executeSql(query);
}
```
