**功能**：结束 AI 执行，返回最终结果给用户

**文件位置**：`tools/TerminateTool.java`

**核心实现**：
```java
public class TerminateTool extends AbstractBaseTool<Map<String, Object>>
        implements TerminableTool {

    public static final String name = "terminate";

    private final String expectedReturnInfo;  // 期望返回的信息格式

    @Override
    public ToolExecuteResult run(Map<String, Object> input) {
        String message = (String) input.get("message");

        // 验证 message
        if (message == null || message.trim().isEmpty()) {
            return new ToolExecuteResult(
                "Error: 'message' parameter cannot be empty"
            );
        }

        // 返回终止消息
        return new ToolExecuteResult(message);
    }

    @Override
    public boolean canTerminate() {
        return true;  // 标记为可以终止的工具
    }
}
```

```java
}

// DynamicAgent 检测到 TerminateTool
// → 设置 shouldTerminate = true
// → 优雅地结束执行
```

### 1.2 FormInputTool - 用户输入工具

**功能**：暂停 AI 执行，等待用户输入

**文件位置**：`tools/FormInputTool.java`

**核心实现**：
```java
public class FormInputTool extends AbstractBaseTool<FormInputTool.FormInputRequest>
        implements TerminableTool {

    // 输入状态
    public enum InputState {
        AWAITING_USER_INPUT,  // 等待用户输入
        INPUT_RECEIVED,       // 已收到输入
        TIMEOUT,             // 超时
        CANCELLED            // 用户取消
    }

    private volatile InputState inputState = InputState.AWAITING_USER_INPUT;

    @Override
    public ToolExecuteResult run(FormInputRequest request) {
        // 1. 设置状态为等待输入
        inputState = InputState.AWAITING_USER_INPUT;

        // 2. 存储到 UserInputService
        userInputService.saveFormInput(
            getCurrentPlanId(),
            request.getFormSchema()
        );

        // 3. 等待用户输入（阻塞）
        waitForUserInputOrTimeout();

        // 4. 获取用户输入
        String userInput = userInputService.getUserInput(getCurrentPlanId());

        // 5. 返回结果
        return new ToolExecuteResult(
            "User input: " + userInput
        );
    }

    private void waitForUserInputOrTimeout() {
        long startTime = System.currentTimeMillis();
        long timeoutMs = getLynxeProperties().getUserInputTimeout() * 1000L;

        while (inputState == InputState.AWAITING_USER_INPUT) {
            // 检查超时
            if (System.currentTimeMillis() - startTime > timeoutMs) {
                inputState = InputState.TIMEOUT;
                break;
            }

            // 检查中断
            if (!agentInterruptionHelper.checkInterruptionAndContinue(getRootPlanId())) {
                inputState = InputState.CANCELLED;
                break;
            }

            // 轮询等待
            try {
                TimeUnit.MILLISECONDS.sleep(500);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
                inputState = InputState.CANCELLED;
                break;
            }
        }
    }
}
```

**使用场景**：
```
AI："请输入数据库密码"
    ↓
调用 FormInputTool
    ↓
暂停执行，等待用户输入
    ↓
用户输入：******
    ↓
继续执行
```

**关键特性**：
- 阻塞等待用户输入
- 支持超时机制
- 支持用户中断
- 可以收集结构化数据（表单）

```java
@Component
public class DatabaseReadTool extends AbstractBaseTool<DatabaseRequest> {

    @Override
    public ToolExecuteResult run(DatabaseRequest request) {
        String action = request.getAction();

        switch (action) {
            case "execute_read_sql":
                // 安全检查：只允许 SELECT
                String query = request.getQuery();
                if (query != null && !query.trim().toUpperCase().startsWith("SELECT")) {
                    return new ToolExecuteResult(
                        "Only SELECT queries are allowed in read-only mode"
                    );
                }
                return new ExecuteSqlAction().execute(request, dataSourceService);

            case "get_table_name":
                return new GetTableNameAction(objectMapper)
                    .execute(request, dataSourceService);

            case "execute_read_sql_to_json_file":
                return new ExecuteSqlToJsonFileAction(
                    directoryManager, objectMapper, rootPlanId
                ).execute(request, dataSourceService);

            default:
                return new ToolExecuteResult("Unknown action: " + action);
        }
    }

    // 返回当前状态
    @Override
    public String getCurrentToolStateString() {
        Map<String, String> datasourceInfo =
            dataSourceService.getAllDatasourceInfo();

        StringBuilder state = new StringBuilder();
        state.append("=== Database Read Tool Current State ===\n");
        state.append("Available datasources:\n");

        for (Map.Entry<String, String> entry : datasourceInfo.entrySet()) {
            state.append(String.format("  - %s (%s)\n",
                entry.getKey(), entry.getValue()));
        }

        return state.toString();
    }
```

```java
public class PythonExecute extends AbstractBaseTool<PythonExecute.PythonInput> {

    public static class PythonInput {
        private String code;           // Python 代码
        private String dependencies;  // 依赖包

        // getter/setter...
    }

            // 1. 安装依赖
            if (dependencies != null && !dependencies.isEmpty()) {
                installDependencies(dependencies);
            }

            // 2. 执行代码
            ProcessBuilder pb = new ProcessBuilder("python3", "-c", code);
            pb.directory(unifiedDirectoryManager.getWorkingDirectoryPath());

            Process process = pb.start();

            // 3. 获取输出
            String output = IOUtils.toString(process.getInputStream());
            String error = IOUtils.toString(process.getErrorStream());

            process.waitFor();

            // 4. 返回结果
            String result = output;
            if (!error.isEmpty()) {
                result += "\n[ERROR]\n" + error;
            }

            return new ToolExecuteResult(result);

        } catch (Exception e) {
            return new ToolExecuteResult(
                "Python execution failed: " + e.getMessage()
            );
        }
```

```java
public class FileSplitterTool extends AbstractBaseTool<FileSplitterTool.FileSplitterInput> {

    @Override
    public ToolExecuteResult run(FileSplitterInput input) {
        String filePath = input.getFilePath();
        int linesPerFile = input.getLinesPerFile();

        try {
            File inputFile = new File(filePath);
            BufferedReader reader = new BufferedReader(new FileReader(inputFile));

            String line;
            int fileCount = 0;
            int currentLineCount = 0;
            List<String> currentLines = new ArrayList<>();

            while ((line = reader.readLine()) != null) {
                currentLines.add(line);
                currentLineCount++;

                // 达到分割行数，写入文件
                if (currentLineCount >= linesPerFile) {
                    writeSplitFile(filePath, fileCount++, currentLines);

                    currentLines = new ArrayList<>();
                    currentLineCount = 0;
                }
            }

            // 写入剩余的行
            if (!currentLines.isEmpty()) {
                writeSplitFile(filePath, fileCount++, currentLines);
            }

            return new ToolExecuteResult(
                "File split into " + fileCount + " parts"
            );

        } catch (Exception e) {
            return new ToolExecuteResult(
                "Split failed: " + e.getMessage()
            );
        }
    }
}
```

### 7.4 FileMergeTool - 文件合并工具

**功能**：合并多个文件为一个文件

**文件位置**：`tools/innerStorage/FileMergeTool.java`

**核心实现**：
```java
public class FileMergeTool extends AbstractBaseTool<FileMergeTool.FileMergeInput> {

    @Override
    public ToolExecuteResult run(FileMergeInput input) {
        List<String> filePaths = input.getFilePaths();
        String outputPath = input.getOutputPath();

        try {
            BufferedWriter writer = new BufferedWriter(
                new FileWriter(outputPath)
            );

            for (String filePath : filePaths) {
                BufferedReader reader = new BufferedReader(
                    new FileReader(filePath)
                );

                String line;
                while ((line = reader.readLine()) != null) {
                    writer.write(line);
                    writer.newLine();
                }

                reader.close();
            }

            writer.close();

            return new ToolExecuteResult(
                "Files merged into: " + outputPath
```

```java
public abstract class AbstractBaseTool<I> implements ToolCallBiFunctionDef<I> {

    // 计划 ID 管理
    protected String currentPlanId;
    protected String rootPlanId;

    // 核心执行方法（子类实现）
    public abstract ToolExecuteResult run(I input);

    // BiFunction 接口实现
    @Override
    public ToolExecuteResult apply(I input, ToolContext toolContext) {
        return run(input);
    }

    // 工具信息
    public abstract String getName();
    public abstract String getDescription();
    public abstract String getParameters();
    public abstract Class<I> getInputType();

    // 状态管理
    public abstract String getCurrentToolStateString();
    public abstract void cleanup(String planId);

    // 可选择性
    public abstract boolean isSelectable();
}
```
