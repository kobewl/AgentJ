## 1. 概述

### 1.1 问题背景

**"信息不对称"问题**：
```
没有环境数据注入：
LLM 只能通过历史对话记忆来推测工具状态
→ 推测可能不准确
→ 导致错误的工具调用
→ 执行效率低下

有环境数据注入：
LLM 直接获取工具的真实状态
→ 推测准确
→ 工具调用精确
→ 执行效率高
```

### 1.2 解决方案

**DynamicAgent 的解决方案**：
```
在每个执行步骤开始前：
1. 收集所有工具的当前状态
2. 存储到 envData 中
3. 转换为字符串
4. 注入到 Prompt 中
```

**关键代码**（DynamicAgent.java:1467-1482）：
```java
/**
 * 1.实现环境感知与状态同步
 * 遍历 availableToolKeys，通过调用 collectEnvData 获取每个工具内部维护的 currentToolStateString。
 *
 * 2.解决"信息不对称"问题
 *
 * 如果没有这个方法：LLM 只能依靠历史对话记忆（Chat History）来推测工具状态。
 * Agent 会把工具的真实物理状态 强制注入到当前的 Prompt 上下文中。
 */
public void collectAndSetEnvDataForTools() {
    Map<String, Object> toolEnvDataMap = new HashMap<>();

    // 保留旧数据
    Map<String, Object> oldMap = getEnvData();
    toolEnvDataMap.putAll(oldMap);

    // 覆盖新数据
    for (String toolKey : availableToolKeys) {
        String envData = collectEnvData(toolKey);
        toolEnvDataMap.put(toolKey, envData);
    }

    setEnvData(toolEnvDataMap);
}
```

## 2. 工具环境数据是什么？

### 2.1 定义

**工具环境数据** = 工具在执行过程中维护的状态信息

**特点**：
- ✅ **实时性**：反映工具的当前状态
- ✅ **动态性**：随着工具执行而变化
- ✅ **工具特定**：每个工具维护自己的状态

### 2.2 包含的信息

| 工具类型 | 环境数据示例 |
|---------|-------------|
| **Bash** | 当前工作目录、上次执行的命令、上次执行结果 |
| **Database** | 已配置的数据源、数据源类型（MySQL/PostgreSQL） |
| **Browser** | 当前 URL、页面标题、打开的标签页数量 |
| **FileSystem** | 当前工作目录、最后操作的文件、操作结果 |

### 4.2 核心方法分析

#### 4.2.1 collectAndSetEnvDataForTools()

**DynamicAgent.java（第 1467-1482 行）**：
```java
public void collectAndSetEnvDataForTools() {
    // 1. 创建新的 Map
    Map<String, Object> toolEnvDataMap = new HashMap<>();

    // 2. 保留旧数据（覆盖）
    Map<String, Object> oldMap = getEnvData();
    toolEnvDataMap.putAll(oldMap);

    // 3. 遍历所有可用工具
    for (String toolKey : availableToolKeys) {
        // 4. 调用 collectEnvData() 获取工具状态
        String envData = collectEnvData(toolKey);
        toolEnvDataMap.put(toolKey, envData);
    }

    // 5. 更新 envData（创建不可变副本）
    setEnvData(toolEnvDataMap);
}
```

#### 4.2.2 collectEnvData()

**DynamicAgent.java（第 1439-1456 行）**：
```java
protected String collectEnvData(String toolCallName) {
    // 1. 转换工具名称（支持 serviceGroup.toolName 格式）
    String lookupKey = convertServiceGroupToolNameToQualifiedKey(toolCallName);
    if (lookupKey == null) {
        lookupKey = toolCallName;
    }

    // 2. 获取工具上下文
    PlanningFactory.ToolCallBackContext context =
        toolCallBackContext.get(lookupKey);

    if (context != null) {
        // 3. 调用工具的 getCurrentToolStateString() 方法
        String envData = context.getFunctionInstance()
            .getCurrentToolStateString();
        return envData;
    }

    // 4. 工具不存在，返回空字符串
    log.warn("⚠️ No context found for tool: {}", toolCallName);
    return "";
}
```

public String getCurrentToolStateString() {
    try {
        Map<String, String> datasourceInfo =

}

### 5.3 Browser 工具

**实现**（BrowserUseTool.java:551-585）：
```java
@Override
public String getCurrentToolStateString() {
    // 只有在运行过至少一次后才初始化
    if (!hasRunAtLeastOnce) {
        return """
            Browser tool context is empty
            """;
    }

    DriverWrapper driver = getDriver();
    Map<String, Object> state = getCurrentState(driver.getCurrentPage());

    // 构建当前页面信息
    String urlInfo = String.format(
        "\n   URL: %s\n   Title: %s",
        state.get("url"),
        state.get("title")
    );

    // 构建标签页信息
    List<Map<String, Object>> tabs = (List<Map<String, Object>>) state.get("tabs");
    String tabsInfo = (tabs != null) ?
        String.format("\n   %d tab(s) available", tabs.size()) : "";

    if (tabs != null) {
        for (int i = 0; i < tabs.size(); i++) {
            Map<String, Object> tab = tabs.get(i);
            String tabUrl = (String) tab.get("url");
            String tabTitle = (String) tab.get("title");
            urlInfo += String.format(
                "\n   Tab %d: %s - %s",
                i, tabTitle, tabUrl
            );
        }
    }

    return String.format(
        "Browser tool context:%s%s",
        urlInfo,
        tabsInfo
    );
}
```

**状态示例**：
```
Browser tool context:
   URL: https://www.baidu.com
   Title: 百度一下，你就知道
   3 tab(s) available
   Tab 0: 百度一下，你就知道 - https://www.baidu.com
   Tab 1: GitHub - https://github.com
   Tab 2: Example - https://example.com
```

**维护的状态**：
- `driver.getCurrentPage()` - 当前页面
- `state.get("tabs")` - 打开的标签页列表

## 6. 数据注入到 Prompt

### 6.1 转换为字符串

**DynamicAgent.java（第 1484-1497 行）**：
```java
public String convertEnvDataToString() {
    StringBuilder envDataStringBuilder = new StringBuilder();

    // 遍历所有工具
    for (String toolKey : availableToolKeys) {
        Object value = getEnvData().get(toolKey);

        // 跳过空数据
        if (value == null || value.toString().isEmpty()) {
            continue;
        }

        // 添加工具信息
        envDataStringBuilder.append(toolKey).append(" context information:\n");
        envDataStringBuilder.append("    ").append(value.toString()).append("\n");
    }

    return envDataStringBuilder.toString();
}
```

private Map<String, Object> getMergedData() {
    Map<String, Object> data = new HashMap<>();
